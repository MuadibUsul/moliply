# Prototype archive

Static HTML/JS mock-ups that predate the Next.js storefront. They are kept for
design reference only — nothing here is built, served or imported by the
running product, so a stale selector or hard-coded sample number in these files
is expected.

| File | What it was |
| --- | --- |
| `i6.html`, `ys-i6.html`, `t.html`, `ys-home.html` | Storefront and product-page layout drafts |
| `ys.html`, `s.html` | Early landing-page drafts |
| `ys-reg.html` | Account/registration draft |
| `ys-_.js`, `ys-ctl.js`, `ys-idx.js` | Client-side prototype scripts |
| `ys-data.json`, `ys-items.json` | Sample catalogue payloads |
| `mk.txt` | Empty scratch note |

The live storefront lives in `recharge-gateway-frontend/`; the live API lives in
`recharge-gateway-backend/`. When a visual decision needs to be traced back to
an earlier draft, look here; when in doubt, the Next.js code is authoritative.
